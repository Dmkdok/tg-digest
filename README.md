# 📋 TG Digest

Ежедневный дайджест ваших Telegram-каналов и чатов: собирает сообщения за
последние 24 часа, суммаризирует их через LLM и присылает готовый разбор
прямо в Telegram — без необходимости читать сотни сообщений вручную.

Работает от вашего личного Telegram-аккаунта (через [Telethon](https://github.com/LonamiWebs/Telethon)),
поэтому подходит и для приватных чатов, куда нельзя добавить бота.

## Что делает

- Читает список каналов/чатов из `channels.txt` (публичные — по `@username`,
  приватные — по числовому ID).
- Забирает сообщения за последние 24 часа (настраивается), отфильтровывая
  «шум» — короткие реплики без смысла («спасибо», «+1», эмодзи-реакции и т.п.,
  список — в `filler_words.txt`).
- Для больших чатов использует map-reduce суммаризацию: сообщения режутся на
  чанки, каждый чанк резюмируется отдельно, затем чанк-саммари сводятся в
  единый разбор — так не теряется ни один пласт обсуждения даже в чатах
  на сотни сообщений в день.
- Отдельно выделяет самые залайканные сообщения (по числу реакций) и
  подсвечивает из них действительно полезное.
- Итоговый разбор по каждому каналу — по структуре:
  - **Темы и события** — о чём вообще был день;
  - **Выводы и тезисы** — если в обсуждении родился консенсус, совет или
    решение;
  - **Полезное по реакциям** — что зашло аудитории и стоит внимания.
- Отправляет готовый дайджест в Telegram, автоматически разбивая длинный
  текст на несколько сообщений (Telegram ограничивает одно сообщение 4096
  символами).

## LLM-бэкенд

Скрипт пробует провайдеров по цепочке, пока один не сработает:

1. **Основной / запасной** — облачные модели через [Hermes CLI](https://github.com/NousResearch/hermes-agent)
   (по умолчанию — бесплатные модели Nous Portal, без ключей и лимитов).
2. **DeepSeek** — активируется автоматически, если задан `DEEPSEEK_API_KEY`.
3. **Локальный Ollama** — совместимый `/api/chat` эндпоинт, если задан
   `OLLAMA_CHAT_URL` (последний резерв — самый медленный вариант).

Всё настраивается переменными окружения (см. ниже) — код менять не нужно.

## Установка

```bash
git clone https://github.com/dmkdok/tg-digest.git
cd tg-digest
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

### 1. Авторизация Telegram-аккаунта

```bash
python auth.py
```

Введите номер телефона и код из Telegram — создастся файл `session.session`
(добавлен в `.gitignore`, никогда не коммитьте его — это доступ к вашему
аккаунту).

### 2. Список каналов

```bash
cp channels.example.txt channels.txt
```

Впишите в `channels.txt` свои каналы/чаты — по одному на строку:

```
durov
some_public_chat
-1001234567890
```

### 3. LLM-провайдер

По умолчанию используется [Hermes CLI](https://github.com/NousResearch/hermes-agent)
с бесплатными моделями Nous Portal. Если Hermes не установлен или вы хотите
другой бэкенд — настройте переменные окружения (см. таблицу ниже) под
DeepSeek или свой Ollama-инстанс.

### 4. Запуск

```bash
python fetch_digest.py
```

Скрипт отправит готовый дайджест в Telegram через `hermes send` и напечатает
в stdout, сколько сообщений ушло.

## Настройка через переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TG_API_ID`, `TG_API_HASH` | Telegram Desktop (публичная пара) | Свои значения — на [my.telegram.org](https://my.telegram.org) |
| `TG_SESSION_FILE` | `./session` | Путь к файлу Telethon-сессии |
| `TG_CHANNELS_FILE` | `./channels.txt` | Путь к списку каналов |
| `TG_FILLER_FILE` | `./filler_words.txt` | Путь к списку filler-слов |
| `DIGEST_HOURS_BACK` | `24` | За сколько часов собирать сообщения |
| `HERMES_BIN` | `hermes` | Путь к бинарнику Hermes CLI |
| `NOUS_PROVIDER` | `nous` | Провайдер для Hermes CLI |
| `NOUS_MODELS` | `inclusionai/ling-3.0-flash-fin:free,inclusionai/ling-3.0-flash-sante:free` | Модели через запятую, пробуются по очереди |
| `DEEPSEEK_API_KEY` | — | Включает DeepSeek как fallback |
| `OLLAMA_CHAT_URL` | — | Включает локальный Ollama как fallback (напр. `http://localhost:11434/api/chat`) |
| `OLLAMA_MODEL` | `qwen2.5:3b` | Модель Ollama |

## Автоматизация (cron)

Для ежедневной рассылки настройте cron-задачу на `python fetch_digest.py`.

> ⚠️ Если доставка результата в Telegram у вас идёт не напрямую, а через
> обёртку, которая режет/интерпретирует stdout — учитывайте лимит Telegram
> в 4096 символов на сообщение: скрипт сам шлёт каждую часть дайджеста
> отдельным вызовом `hermes send`, поэтому cron-обёртке не нужно (и не
> следует) пытаться доставить весь stdout как один message.

## Структура репозитория

```
fetch_digest.py       — основной скрипт: сбор, суммаризация, отправка
auth.py                — одноразовая авторизация Telethon
channels.example.txt   — шаблон списка каналов
filler_words.txt        — список слов/фраз-пустышек для фильтрации
requirements.txt        — зависимости
```
